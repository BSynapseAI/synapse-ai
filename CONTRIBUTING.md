# Contributing to Synapse AI

Thank you for your interest in contributing to Synapse AI.

Synapse AI is being developed as an evolving AI platform focused on intelligent AI systems, developer tools, and next-generation AI infrastructure.

## Getting Started

Before contributing:

1. Read the project README.
2. Review the existing documentation.
3. Check open issues and pull requests.
4. Make sure your proposed change aligns with the project's goals.

## Development Workflow

1. Fork or clone the repository as appropriate.
2. Create a dedicated branch for your changes.
3. Make your changes in small, focused commits.
4. Add or update tests when applicable.
5. Verify that the project works correctly.
6. Submit a pull request with a clear description of your changes.

## Pull Requests

Please ensure that pull requests:

* Clearly explain what was changed.
* Explain why the change was needed.
* Include relevant tests where applicable.
* Do not introduce unnecessary dependencies.
* Do not contain secrets, API keys, passwords, or private credentials.
* Keep unrelated changes out of the pull request.

## Code Quality

Write code that is:

* Clear and maintainable.
* Consistent with the existing project structure.
* Properly documented when necessary.
* Tested where practical.

## Security

Never commit:

* API keys
* Access tokens
* Passwords
* Private keys
* `.env` files containing secrets
* Database credentials
* Other sensitive information

If you discover a security vulnerability, please follow the instructions in `SECURITY.md` rather than publicly reporting sensitive details.

## Issues

Use GitHub Issues to report bugs, request features, or discuss improvements.

Before opening a new issue, search existing issues to avoid duplicates.

## Community

Please be respectful, constructive, and professional when participating in the Synapse AI project.

We welcome thoughtful contributions, technical discussions, improvements, and ideas.

Thank you for helping build Synapse AI.
